# EP-05 多 Agent 协作系统

> **Epic 目标**：原生支持 Agent Team，各 Agent 拥有独立子沙箱并共享加密工作记忆，实现真正的多 Agent 并行协作。

- **优先级**：P2
- **阶段**：阶段二（第 2-3 周）
- **状态**：📋 待开始

## 用户故事

| ID | 故事 | 优先级 | 状态 |
|----|------|--------|------|
| S-05-01 | 作为用户，我可以创建一个 Agent Team，指定多个 Agent 并行处理不同子任务 | P1 | 📋 待开始 |
| S-05-02 | 作为 Agent，我拥有独立的子沙箱，与其他 Agent 完全隔离 | P0 | 📋 待开始 |
| S-05-03 | 作为 Agent Team，各成员可通过加密消息总线互相发送消息和任务结果 | P1 | 📋 待开始 |
| S-05-04 | 作为主 Agent，我可以拆分任务、分发给子 Agent，并汇总结果 | P1 | 📋 待开始 |
| S-05-05 | 作为用户，我可以在控制台实时查看每个 Agent 的执行状态和进度 | P1 | 📋 待开始 |

## 验收标准

- [ ] Agent 子沙箱完全隔离，一个 Agent 崩溃不影响其他 Agent
- [ ] Agent 间消息加密传输，使用临时密钥，会话结束后销毁
- [ ] Team 最大支持 10 个并发 Agent
- [ ] 控制台实时展示 Agent 状态（running/idle/error/completed）
