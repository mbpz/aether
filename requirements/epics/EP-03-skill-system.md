# EP-03 渐进式技能系统

> **Epic 目标**：沿用 Manus 的 SKILL.md 标准，升级为三级披露机制（元数据 → 指令 → 资源），最小化 LLM Token 消耗，并建立去中心化可信技能飞轮。

- **优先级**：P1
- **阶段**：阶段一（第 1-2 周）
- **状态**：📋 待开始

## 背景 & 问题

现有技能系统（Manus SKILL.md）在加载时会把全部技能内容塞进上下文，造成 Token 爆炸。同时技能分发依赖中心化服务器，存在供应链安全风险。

## 三级披露机制

```
Level 1 - 元数据（永远加载，<100 tokens）：
  name, description, version, category, trust_score

Level 2 - 指令（按需加载，~500 tokens）：
  system_prompt, input_schema, output_schema

Level 3 - 资源（执行时加载）：
  code, dependencies, secrets_required
```

## 验收标准

- [ ] 三级加载机制：Level 1 常驻，Level 2/3 按需，Token 消耗降低 ≥ 60%
- [ ] 兼容 Manus SKILL.md 格式，100% 无改动运行
- [ ] 兼容 OpenClaw 插件格式，100% 无改动运行
- [ ] 新技能发布后自动触发安全审计，审计完成时间 < 5 分钟
- [ ] 技能市场 API 支持按分类、评分、作者筛选
