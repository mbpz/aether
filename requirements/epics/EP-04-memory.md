# EP-04 分层记忆系统

> **Epic 目标**：建立事件流 + 长期知识库的双层记忆架构，配合 RAG 检索，彻底避免上下文爆炸。

- **优先级**：P1
- **阶段**：阶段二（第 2-3 周）
- **状态**：📋 待开始

## 背景 & 问题

单纯依赖 LLM 上下文窗口存储记忆会导致 Token 爆炸，且跨会话无法持久化。本 Epic 建立两层记忆：
- **短期记忆（事件流）**：当前任务的执行过程，滚动窗口
- **长期记忆（知识库）**：提炼后的结构化知识，RAG 检索

## 架构设计

```
短期记忆（事件流）：
  Agent 行动 → timeline.log → 滚动窗口（最近 N 条）→ LLM 上下文

长期记忆（知识库）：
  事件流 → 自动提炼 → 向量数据库（本地）→ RAG 检索 → LLM 上下文
```

## 验收标准

- [ ] 事件流支持按 session_id 检索和回放
- [ ] RAG 检索延迟 < 200ms（本地向量库）
- [ ] 记忆数据全部存储在本地，无任何云端调用
- [ ] 多 Agent 共享记忆时使用加密传输（AES-256）
