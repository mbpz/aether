## MVP 验收指标

- [ ] 一个 Agent 能在 WASM 沙箱里执行代码
- [ ] 尝试外联被 eBPF 拦截，日志可查
- [ ] Gateway 接收一个请求，通过 Manifest 验证后转发到沙箱执行
- [ ] 加载一个现有的 Manus 技能并执行成功

## 技术选型

| 模块 | 选型 | 备注 |
|------|------|------|
| WASM Runtime | Wasmtime | Rust 实现，性能最优 |
| eBPF | libbpf + Rust | cilium/ebpf-go 备选 |
| 本地模型 | Ollama + DeepSeek-R1 | Qwen 备选 |
| 向量数据库 | Qdrant（本地） | 轻量，无需云服务 |
| 区块链身份 | GitHub（MVP阶段） | 后期升级到 Solana |
| K8s 部署 | Helm Chart | 阶段四交付 |
